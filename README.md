Sarjy - your voice assistant 
This app has the following abilities
1. Login/signup
2. Speech recognition buttons to start and stop
3. Display the recognised speech on the screen
4. Sends speech to openai llm and gets response
5. Respond in audio and text

Next:
1. Pass response id in llm calls to keep short memory 
2. Save conversation in db - long term memory

Nice to have:
1. Show speech-loading UI while the browser is listening to give instant feedback to the user after they speak  
2. ability for user to choose llm model
